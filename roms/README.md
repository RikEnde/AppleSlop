# ROM inputs

The existing ROM images are used by the emulator and copied into its desktop
jar: `apple2plus.rom` (12,288 bytes, Applesoft and Autostart monitor), `video.rom`
(2,048 bytes, character generator), and `disk2.rom` (256 bytes, Disk II boot ROM).
These Apple ROMs are not covered by the project's BSD source licence.
Their original acquisition source was not recorded in this checkout.
Use `--roms DIR` to supply alternative compatible images.
