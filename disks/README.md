# Disk images

- `dos33-master.dsk`: 143,360-byte DOS-order image. Boots DOS 3.3 System Master;
  `CATALOG` lists files. Used by the boot/save/reload regression test.
- `prodos-2.4.3.po`: 143,360-byte ProDOS-order image already present in the
  checkout. It is not part of the boot regression tests.

These operating-system images are third-party material, outside the project's
BSD source licence. Their acquisition sources were not recorded in this
checkout. Desktop use can modify writable images; use a copy to preserve them.
Regression tests operate on in-memory copies.
